## 💳 How Ordering & WhatsApp Works

1. Customer chooses pen quantity & ink color (Blue/Black).
2. Customer enters Delivery Address, Name, and Phone number.
3. Customer pays total amount (including flat ₹1 delivery) to **99220 91507** via PhonePe, Google Pay, Paytm, etc.
4. Customer pastes their payment **Transaction ID / UTR**.
5. Customer clicks **"Confirm & Send Order to WhatsApp"**:
   - Order receipt is saved to their browser.
   - WhatsApp opens immediately in chat with Store (**+91 99220 91507**) with complete pre-filled details (Order ID, Customer Name, Address, Items, Quantities, Total with ₹1 Delivery, and Transaction ID).
   - Customer also gets a printable/downloadable digital invoice & receipt on screen.

## 🚀 How to Deploy on GitHub Pages (Free Hosting)

1. Create a new repository on [GitHub](https://github.com/new) named `zep-pen` (or any name).
2. Push this project to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial release of Zep Pen storefront"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** → **Pages** (under Code and automation in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select branch **`main`** and folder **`/(root)`**, then click **Save**.
4. In 1 minute, your website will be live at:
   `https://<YOUR_USERNAME>.github.io/<YOUR_REPO>/`

## 📱 How to Install as Mobile App / APK

### Instant Install (PWA):
1. Open your GitHub Pages link in **Google Chrome** on an Android phone.
2. Tap the **"Install App / APK"** button or Chrome's three dots (`⋮`) menu.
3. Tap **"Install app"** or **"Add to Home Screen"**.
4. The Zep Pen icon will appear on your phone home screen just like a regular APK!

### Build Standalone `.apk` File:
1. Go to [PWABuilder.com](https://www.pwabuilder.com/).
2. Enter your GitHub Pages URL.
3. Click **"Package for Android"** → **"Download APK"**.
